# 변화유무 학습데이터 구축 가이드라인 요약

## 기본 단위

- 20m x 20m 격자 크기 기준으로 구축한다.
- 두 시점 항공영상 T1, T2를 비교한다.
- 단순 밝기, 그림자, 촬영 조건, 계절 차이만으로는 변화로 판단하지 않는다.

## 인공물 변화

| 라벨 | 의미 |
|---|---|
| `arti` | 인공물 변화 전체 |
| `arti_bu` | 건물 신축, 철거, 구조 변화, 명확한 지붕 색상 변화 |
| `arti_bu_t` | 촬영각에 따른 건물 기울임 변화 |
| `arti_binil` | 온실/비닐하우스 설치, 철거, 형태 변화 |
| `arti_road` | 도로 신설, 폐쇄, 형태, 폭, 노면 변화 |
| `arti_roa_m` | 도로 표식, 차선, 횡단보도, 문자, 기호 변화 |
| `arti_other` | 적치물, 옹벽, 토지변형, 건축중, 태양광패널 등 |

## 비인공물 변화

| 라벨 | 의미 |
|---|---|
| `tree` | 나무 개체수, 크기, 밀도, 잎/꽃 변화 |
| `fore` | 산림 벌목, 산불, 조림 등 |
| `farm` | 농경지 구조, 고랑, 비닐멀칭, 재배 패턴, 생육 단계 변화 |
| `water` | 물웅덩이, 저수지, 강, 바다, 수위 변화 |

## LLM 판단 원칙

- 애매하면 `review_required=true`로 둔다.
- 신뢰도가 낮으면 육안검수 대상으로 보낸다.
- 기존 라벨과 LLM 라벨이 다르면 육안검수 대상으로 보낸다.
